Это предупреждение касается не только accrue_events.py — datetime.utcnow() мы используем везде в проекте: в моделях, в auth_bp, во всех cron-скриптах.
Нужно заменить во всём проекте. Правило простое:
python# было
from datetime import datetime
datetime.utcnow()

# стало
from datetime import datetime, timezone
datetime.now(timezone.utc)
В моделях где используется default и onupdate:
python# было
default=datetime.utcnow
onupdate=datetime.utcnow

# стало
default=lambda: datetime.now(timezone.utc)
onupdate=lambda: datetime.now(timezone.utc)
Обрати внимание — в default передаём не вызов функции а ссылку на неё или lambda. Без скобок, иначе значение вычислится один раз при старте приложения а не при каждой вставке.
Затронутые файлы:

app/models.py — все модели где есть default=datetime.utcnow
app/routes/auth.py — datetime.utcnow() в нескольких местах
cron/accrue_events.py
cron/cleanup_tokens.py
cron/fetch_quotes.py
cron/fetch_history.py
cron/fetch_corporate.py
